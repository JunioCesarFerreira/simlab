# Debug Docker Catalog

- [**minimal-infra**](minimal-infra/README.md): a minimal infrastructure to run SimLab locally or on machines with limited resources.
- [**mongo-cooja**](mongo-cooja/README.md): MongoDB, eight Cooja containers and the monitoring pair, to run the Python components on your local host.
- [**remote-host**](remote-host/README.md): a simulated remote host, to exercise the distributed path on one machine, next to the main stack.
